# 2.2 古城行动

在原来的 lotus-moba 工程和 dist/index.html 上更新，未创建第二个游戏或第二个域名。原本的 http://localhost:8778/ 刷新后就是新版；build 参数只是区分缓存的查询参数，不是另一份工程。

## 新玩法与引导

- 地面光点 + 小地图虚线：根据当前包点命令、已安装/掉落的 Spike 或 MOBA 可攻击建筑生成真实可通行路线。每1.2秒最多刷新一次；可关闭；前路无法到达时显示受阻，不把直线穿墙当导航。
- 预算内快速配装：经济保留、均衡配装、火力优先。点击只更新选择，不立即扣款；保留已有更高价值枪械，确认出发才结算。
- 阵亡报告：显示真实最后伤害来源、武器或技能，以及最近8秒承受伤害。其余队友继续对局。
- 回合战报：有效伤害、射击命中率、安拆参与、下回合资金、MVP与规则生成的建议。霰弹枪按实际发射弹丸统计命中率。MVP为本原型内部评分，不声称官方评价。

## 美术与交互

- 独立英雄展示台：三层底座、双侧灯柱、细环与36点单批粒子。大厅与战场分组切换，展示台不会出现在对局中。
- 大厅、武器库、结算统一为深石板蓝、象牙文字、暖铜主按钮；两种模式会更新大厅说明和开始按钮。
- 战报重排层级，武器库增加快速配装，手机高度较小时收起装置说明、压缩固定行，保留枪械滚动区域。
- 场景与界面均延用原有Three.js、原创几何体、原版枪图来源及既有许可声明；不新增运行依赖。
