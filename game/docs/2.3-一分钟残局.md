# 2.3 一分钟残局

定位：给暂时无法开一局 MOBA / 战术射击的玩家，提供 50–70 秒的俯视角战术挑战。保留原工程、原网址、原 MOBA 和五回合爆破。新增模式不依赖队友 AI。

## 已实现

- B 点回防：1v2，55 秒，消灭敌人后仍必须完成 7 秒拆包。
- C 点守包：1v3，50 秒，可以拖延引爆或歼敌；敌人会实际拆包，开始时有文字与提示音。
- A 点清场：1v3，70 秒，限时消灭全部守卫。
- 三选一主武器（狂徒 / 幻影 / 骇灵）与一次性侦察 / 急救 / 超频装置，开局无商店等待。
- 三星评价、用时/伤害/击杀/积分、即时重试；通关记录保存在本机。
- 关间选择收割回血、技能冷却或护甲移速强化，带入后续关卡。
- 修复原爆破队友向持包玩家同一坐标汇聚：跟随也使用编队偏移；友军增加软避让，不推玩家，不打断安拆。
