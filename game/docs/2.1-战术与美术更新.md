# 2.1 战术协作与美术更新

## 已实现

- MOBA、SPIKE均可指挥：集结A/B/C、跟随、守住当前位置、自主配合。界面显示队友当前任务与双方存活人数。明确命令改变实际AI目标，不只是播报。
- SPIKE：贤者优先治疗附近伤员，其他英雄按距离/状态选择技能；换弹时寻找掩护，低血换位；空闲补弹；保留已有高价枪，按预算买枪甲。
- 敌情由队伍实际视线发现后共享，6秒过期；防守根据情报支援，安装后回防。指定最近队员拆除，其余队员守周边。不会因为真人活着却远离包点而无人拆包。
- 每回合免费三选一装置，每回合只能启动一次：侦察脉冲（22米、6秒显形/小地图）、急救（10米友军回复35）、超频（6秒加速/射速提升、三个小技能各减4秒）。按Y或点按钮；施法压制、眩晕、阵亡、安拆中不能用。
- 击杀掉枪40秒。靠近按X拾取，保留剩余弹药，旧枪落地；存活可保留到下一回合。附近AI也会升级到更高价值掉枪。
- 携带Spike时可交给附近7米、实际视线可达的存活AI队友，让真人先手或掩护。
- 每次浏览器新对局使用随机种子，测试仍可固定种子复现。固定5回合及800起始经济不变。
- 青蓝战术HUD/暖色开火按钮、敌我头顶标记、受击标记脉冲、原创角色头部描边、掉枪品质圈和拾取标签、战术集结标记、石墙结构线、较整洁的地面大砖分区、包点边界刻线与灯柱。
- 保留手机摇杆与安全区、全屏进出/尺寸重算，以及A高台实体底座。
