两个 npm 包从官方 registry 取固定版本压缩包，核对 registry 的 SHA-512 integrity 后只抽取分发文件，没有运行仓库安装脚本。记录见 docs/*-package.json。均无运行时依赖；未做全面安全审计。three.js 仓库仍活跃；nipplejs 已有新主版本，这里选稳定的 0.10.2 API，并通过本项目触屏包装验证，不把旧版当成最新版本。MIT 许可证全文随 vendor 保留。

Kenney 文件映射：knife_slice.ogg → attack.ogg；chop.ogg → hit.ogg；door_open_1.ogg → gate.ogg；metal_pot_1.ogg → break.ogg；cloth_1.ogg → zip.ogg。仅将拟音用作替代音效，没有声称这是原版游戏音效。镜像 LICENSE 为 CC0；Kenney 官方 RPG Audio 页面搜索结果也标注 CC0。CC0 全文见 dist/audio/CC0-LICENSE.txt。可在 audio.mjs 中替换成同等许可的 WAV/OGG/MP3；保留各资源许可证。

## 你提供的仓库逐项结果

- https://github.com/raywenderlich/unity-moba ：公开链接返回 404；没有下载或声称集成。
- https://github.com/kenneywings/kenney-assets ：公开链接返回 404；改用上表已核验 Kenney RPG Audio 镜像。
- https://github.com/tuxalin/lowpoly-environment ：公开链接返回 404；改用原创低模几何体。
- https://github.com/godotengine/godot-demo-projects ：真实仓库，MIT；没有核实到所述 mobile/fullscreen 独立示例，也未复制 Godot 脚本。不同引擎代码不能直接接到浏览器工程。全屏及横屏改用浏览器 API。
- https://github.com/Unity-Technologies/NavMeshComponents ：真实仓库，MIT；官方说明停止在此仓库开发，迁入 AI Navigation package。它提供导航网格构建组件，并不包含完整推塔、支援、守塔决策。浏览器工程没有复制 Unity C#，使用原创 A* 与优先级 AI。
