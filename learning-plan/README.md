## 韩语学习流程
打开官方视频/图文 → 中文导读与日语对照 → 每课六道原创巩固题 → 逐题解释与错题筛选 → 次日复习。

- 第 1 课按官方编号保留准备讲座，另有基本字母、复合元音、收音三个准备视频。
- 第 7 课内容较多，可分多天；没有每日必须完成一整课的限制。
- 提交测验后安排次日复习；复习答错隔天再练，答对三天后再练。同日重做不会推迟旧复习。
- 三个步骤勾选且测验至少 80%（六题对五题）可完成课程。第 11–43 课只占位。
- 旧版韩语数据归档，可在学习感想底部查看，不套用到新视频课程；AI 与校内数据保持独立。
